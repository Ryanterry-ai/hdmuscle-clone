================================================================================
                    NETLIFY DEPLOYMENT GUIDE
================================================================================

OPTION 1: DRAG & DROP (FASTEST)
================================================================================

1. Go to https://app.netlify.com
   - Sign up free with GitHub, GitLab, or Email

2. Click "Sites" in left sidebar

3. Look for "+ Add new site" button
   - Click it → select "Deploy manually"

4. Drag your zip file: hdmuscle-clone-netlify-deploy.zip
   
5. Wait for Netlify to build (1-3 minutes)

6. DONE! Your site is live at:
   https://random-name.netlify.app

7. To connect your domain:
   - Click "Domain settings" in Netlify
   - Add your custom domain
   - Follow Netlify's instructions to update DNS

---

OPTION 2: WITH GITHUB (RECOMMENDED FOR UPDATES)
================================================================================

1. Create GitHub repository:
   - Go to github.com
   - Create new repo: hdmuscle-clone
   - Upload all files from your project folder

2. Connect to Netlify:
   - In Netlify: Sites → Add new site → Import an existing project
   - Authorize GitHub
   - Select your repo: hdmuscle-clone
   - Click "Deploy"

3. Any changes pushed to GitHub will auto-deploy!

---

AFTER DEPLOYMENT - CONNECT YOUR DOMAIN
================================================================================

1. In Netlify, go to your site
2. Click "Domain settings" 
3. Click "Add custom domain"
4. Enter: hdmuscle.in (or your domain)

5. Update DNS at your domain provider:
   
   For hdmuscle.in:
   - Go to your domain provider (GoDaddy, BigRock, etc.)
   - Find DNS settings
   - Add/CNAME record:
     Name: @ (or leave blank)
     Value: your-netlify-app.netlify.app
   
   OR add A record:
     Name: @
     Value: 75.2.75.164 (Netlify's IP - may vary)

---

TROUBLESHOOTING
================================================================================

Q: Build failed?
A: Check if netlify.toml is in root folder
   Ensure Node version 20 is set

Q: Images not loading?
A: This is normal - images come from hdmuscle.com CDN
   Make sure site is live there

Q: Site looks different?
A: Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)

Q: Custom domain not working?
A: DNS changes take 24-48 hours to propagate
   Keep checking after 24 hours
