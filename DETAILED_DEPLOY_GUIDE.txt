================================================================================
                    HD MUSCLE - HOSTINGER DEPLOYMENT GUIDE
================================================================================

STEP 1: LOGIN TO HOSTINGER
================================================================================
1. Go to: https://www.hostinger.in/login
2. Login with your email and password
3. You will see your Hosting panel (dashboard)

================================================================================
STEP 2: FIND FILE MANAGER
================================================================================
Option A - From Dashboard:
1. On the left sidebar, click "File Manager"
   OR
2. Scroll down to "Advanced" section and click "File Manager"

Option B - If you don't see File Manager:
1. Click on your active hosting plan (the main hosting item)
2. Look for "File Manager" in the new page

NOTE: If still not visible, look for:
- "Website" section
- Or "Files" section in the menu

================================================================================
STEP 3: UPLOAD ZIP FILE
================================================================================
1. Once in File Manager:
2. Click on "public_html" folder (or your domain folder)
3. Look for "Upload" button at top
4. Click it and upload: hdmuscle-clone-hostinger-deploy.zip

OR use FTP:
- Use FileZilla or any FTP client
- Host: your FTP hostname (from hosting panel)
- Connect and upload files

================================================================================
STEP 4: EXTRACT ZIP
================================================================================
1. In File Manager, find the uploaded zip file
2. Right-click on it
3. Click "Extract"
4. Select public_html as destination
5. Click "Extract Now"

================================================================================
STEP 5: SET UP NODE.JS
================================================================================
Go back to Hosting Panel:

Option A:
1. Look for "Advanced" in sidebar
2. Click "Node.js" or "PHP Manager"

Option B:
1. Click on your hosting plan
2. Look for "Node.js" or "PHP"

If Node.js is not available, try:
1. Go to "PHP Manager" 
2. Select PHP version 8.0 or higher

================================================================================
STEP 6: INSTALL & BUILD (USING TERMINAL)
================================================================================
In File Manager, look for "Terminal" button:
1. Click Terminal
2. Navigate to your project folder:
   cd public_html

3. Install dependencies:
   npm install

4. Build the project:
   npm run build

If npm install fails, try:
   npm install --force
   npm install --legacy-peer-deps

================================================================================
STEP 7: RUN THE APP
================================================================================
After successful build:

Option 1 - Using Hostinger Node.js manager:
1. Go to Node.js section
2. Set:
   - Application entry point: server.js
   - Application URL: (choose your domain)
   - Switch from "development" to "production"

Option 2 - From Terminal:
   npm start

This will start your site on port 3000

================================================================================
STEP 8: ACCESS YOUR SITE
================================================================================
Your site should now be live at:
- Your domain.com (if pointed to public_html)
- Or yourdomain.com:3000 (while testing)

================================================================================
IF STILL NOT WORKING - ALTERNATIVE METHOD
================================================================================

Use Netlify (Easier - Free):

1. Go to https://netlify.com
2. Sign up with GitHub or Email
3. Upload the zip file directly in Netlify dashboard
4. Netlify will auto-detect Next.js and deploy!
5. Connect your domain in Netlify settings

This is MUCH easier than Hostinger!

================================================================================
GETTING HELP
================================================================================

If File Manager is still not visible:
- Contact Hostinger support via chat
- Ask them: "Where is File Manager in my hosting panel?"

For Netlify alternative:
- They have automatic Next.js detection
- Just drag and drop your files
